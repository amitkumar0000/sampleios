# SampleModules — binary distribution

This branch ships the `SampleModules` package as **pre-compiled XCFrameworks**.

| Product   | Modules          |
|-----------|------------------|
| ProductA  | Network + Logger |
| ProductB  | Network          |

The `Package.swift` on this branch uses `.binaryTarget` entries whose `url`
points at the `*.xcframework.zip` assets attached to a GitHub Release, together
with a `checksum`.

## Consume in Xcode (SPM)

`File ▸ Add Package Dependencies…` and paste:

```
https://github.com/amitkumar0000/sampleios.git
```

Choose **Branch: `binary`**, then add `ProductA` and/or `ProductB` to your target.

Or in a `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/amitkumar0000/sampleios.git", branch: "binary")
],
targets: [
    .target(name: "MyApp", dependencies: [
        .product(name: "ProductA", package: "sampleios")   // Network + Logger
        // .product(name: "ProductB", package: "sampleios") // Network only
    ])
]
```

Then import the modules (same as source mode):

```swift
import Network
import Logger
```

## Notes

- Binaries are **static** XCFrameworks built with `BUILD_LIBRARY_FOR_DISTRIBUTION`
  (library evolution enabled).
- Slices: `ios-arm64` (devices) and `ios-arm64_x86_64-simulator` (Apple silicon
  + Intel simulators).
- This branch is generated by `scripts/release.sh`; do not edit it by hand.
